     - R100自由态在7千–1.3万次之间同样与自身点估计相反。
3. **S失败的原因：最大偏移来自启动态的外推，不是学到的启动补偿。**
   - 最大的20个偏移里有19个是各actor连接的第一条转移。那时历史除最新帧外全为0，pacing/max_bw被观测峰值归一化放大到3.8–10（10是截断值）。

   - 这是全局权重变化在超范围输入上的线性放大。

4. **正面结果。**
   - 在E1R显著的6个格子里，critic的符号最终全部一致：H1从7千次起、H2从2千次起一直一致，终点（4万/1万次）也一致。

- **P2（长RTT自由态）：** R200自由态的可见持续响应在λ≥15时为正。按E1R的效应量，样本扩大约15倍后40步累计的期望z约为2.0，所以P2可能仍不显著；不显著时该格记为未验证，不作门格子。R100自由态在λ≤8为正、λ≥15为负。
- **P3（critic）：**
  - 传播效率0.75–0.95；
  - R200排队态在λ≈23（约2.5万–3.2万次）后才自身落地，之前会出现借来的符号；
  - R20/R50/R100在1万次以内落地。
- **P4（门）：** 在3万–4万次之间通过。若某个门格子与critic相反，或R200自由态显著为正而critic为负，就不放行。
- **不通过时：** 不放actor，按不一致的格子诊断：数据不平衡（R200自由态约占R200数据的9%）、表征分不开，或E1与dQ/da的口径差。

### 5.3 L2-B（只在L2-A门通过后）

- 从L2-A的checkpoint续跑；如果流程不支持续跑，就在同一流程里先重跑同样长度的critic-only阶段。
- actor学习率1e-6；总预算120万条（含L2-A）。
- 保护：S1–S3＋S5（探针统一同号饱和）、快照、停止时策略。
- 评测：110次冻结评测，用`adjudicate_learning.py`判定。
- 若流程支持"放行令牌"，也可以把L2-A和L2-B合成一次运行：learner停在critic-only，等离线门审计通过后由操作者放行；超过上限仍未通过则记STOP_GATE。
- **预测：**
  - 不触发停止；
  - R20排队态和自由态向负，长RTT自由态的方向跟随E1；
  - A0明显差于A4g，差异集中在连接开始的头几秒（启动态外推），trim10会掩盖一部分。

### 5.4 M3：启动态

- L2-B之后作为单变量：训练中周期性重建连接，例如每20–40秒随机一次，让零填充历史和被放大的pacing/max_bw进入训练分布。
- 评测比较A0与A4g。A5（观测结束后接管）只作评测对照，不进训练。

## 8 更正与边界

- **S的探针设计有缺陷：** 每actor的第0号探针恰好是零填充的连接首条，原预测没有把它们和稳态分开。这是我设计探针时的疏漏。
- **H1的原预测把"首次翻号"当成观测量：** 没有考虑跨组泛化，按登记口径失败。"自身落地在2.7万次"是事后解读，P3用来前瞻检验。
- **撤回上轮的放行门。**
- **E1R的三项预测：**
  - "R20排队态3步累计<0"成立（−0.677±0.061）；
  - "长RTT排队态40步累计≤0"成立（R100为−0.298±0.157，R200为−0.214±0.085）；
  - "长RTT自由态40步累计>0"未确立（R100为−0.005±0.325，R200为+0.817±1.523）。
- **口径边界：**
  - E1是探索创新在当前反馈/补偿协议下的简化式响应，不等于持续动作效应或dQ/da；
  - visible_persistent是线性叠加的启发式；
  - λ是描述性拟合。
  - 本文的"借来"判断依赖这三者，结论限于"该组自身数据在当时的视野内不能支持这个符号"。
