# 连续双动作：问题证据与下一步修复方案

本文件是离线分析和待实施方案，不是已上线算法或成功训练声明。用户最新明确要求**时间头保持连续，不离散化**；此前与Claude讨论的五档选时建议撤回。20/40/80/120/160ms可用作诊断锚点，不作为未来策略的动作集合。

当前唯一健康基座仍为原seed3单动作模型，main/c67717d及保护包保持不变。本轮没有SSH、新TCP、优化器更新或模型改写。新增的是只读审计工具、小指标和本文。审阅基础为[d700cda报告](https://github.com/fiberpine/Canopy/blob/d700cdac809d8d00f213d4ea4b90febf99c1027d/docs/JOINT_COST_PRESERVE_REPAIR_20261116.md)。

## 1. 当前究竟失败在哪里

## 2. 新增离线证据：成本收益比原价值准入细得多

只读工具[tools/audit_joint_period_value.py](../tools/audit_joint_period_value.py)使用已在本机的最终完整CP、960分层真实SMDP转移和175冻结输入。未下载新数据、未更新参数；所有模型变量前后逐位一致。指标见[period-value-decomposition.json](../evidence/joint-continuous-plan-20261116/period-value-decomposition.json)。

960条为每actor每精确周期8条，即每周期192条。它们来自混合探索行为、不同状态/窗口/历史策略，不是随机配对干预、回放总体或连续MC轨迹。

|执行周期|观察效用密度均值|Q1确定性TD RMSE|Q2确定性TD RMSE|
|---|---:|---:|---:|
|20ms|0.89292|0.40876|0.38108|
|40ms|0.88508|1.02686|0.64237|
|80ms|0.87159|0.78772|0.76417|
|120ms|0.80350|1.00677|0.98803|
|160ms|0.80342|1.42423|1.32402|

这里明确省略新抽取的target-window smoothing，属于确定性target诊断。3个物理重连标记按实际`bootstrap_last_observation`视为非Bellman终点。效用从s1原七维前缀重建，奖励误差7.19e-7。**表中差异不能证明长周期使效用下降，也不能证明critic排序错误。TD残差不是动作差误差的置信界。**

一个应当正确区分的解析例子：固定效用u=1、c=.01、gamma=.995/20ms，假设只改当前一次等待，后续仍回到20ms策略，则

`Q(T)-Q(20)=c*(D20-DT)/(1-D20)`。

20→40/80/160ms的优势仅0.00995/0.029701/0.068614。若从此以后始终采用该周期，固定策略价值才分别是198.99749/199.49623/199.74559，对比20ms的198。这两个任务不同；此前“各周期固定策略解析Q”只能测网络能否移动，不能拿来标定当前单步mixed后继Q。

实际冻结输入上，保持同一窗口动作，learned minQ20约168.966，Q40约168.545。这个0.42的短周期偏好大于上述理想单次调用收益，**真实TCP的效用及后继状态也会改变，不能因此认定Q有错或c=.01不可学。** 当前相对误差门不足以判断排序，才是可确认的问题。

## 3. 推荐实现：连续T先输出，窗口根据本次T适配

推荐候选为`T=mu_T(s)`、`a_c=mu_c(s,T)`，critic仍为`Q(s,a_c,T)`，实际SMDP回报仍按真实dt计算。最终两分支都学习。只在必要的迁移/critic校准阶段暂冻窗口，不把冻结窗口学时间当最终创新。

窗口保留原70维迁移主干，加读取当前连续T的轻量残差条件分支。建议在窗口tanh之前写`z_c=base(s)+log(T/20)*r(s,log(T/20))`；残差零初始化，20ms分支在结构上等于base，base仍可学习。先验证初始化窗口函数逐项一致，原BN统计保留。本次T必须在执行同一次窗口动作之前进入窗口条件网络，可以用一次图执行中的数据流完成，不需要部署端额外teacher推理或重复候选网络调用。

**探索若改变实际T，必须用改变后的T重新计算条件窗口；target同样先定T再算窗口。** 只给原无噪声窗口配一个随机T，会再次产生不匹配样本。连续局部探索与全范围探索可作为图输入/图内数据流处理，不能为省一次函数调用而破坏该条件关系。回放保存实际执行的两个动作。

联合阶段时间梯度包含`dQ/dT + dQ/da_c * da_c/dT`，不能误用stop_gradient切掉后半项。teacher参考优先只约束learner中的T=20ms分支，降低对基座窗口能力的破坏；不要求长周期复刻同一短周期每次乘数，不把teacher损失偷偷变成时间头奖励。条件输入、参考、迁移和梯度各自单独验证，不能一次改完后靠吞吐猜原因。

当前条件分支只是候选设计。长周期所需窗口修正可能超过原1/4—4倍范围；网络换结构不能解决真实执行器范围限制。

## 4. 连续时间参数化与探索

候选采用`T=20+140*sigmoid(z)`，再转回原协议连续log坐标；单位是ms。将当前fresh20.5ms/无新RTT时clip(minRTT,40,120)的先验转成相应sigmoid logit，残差零初始化，使初始实际周期函数保持一致。

同一T=20.2ms，原softsign再log映射的`dT/dresidual≈.001924ms`，候选物理周期sigmoid的`dT/dz≈.199714ms`。这是约104倍的局部尺度差异，不是全网络学习速度比，也不证明新方法已成功。候选仍在边界附近衰减，不能宣传消除了饱和。必须重新校准学习率与实际ΔT，不能沿用time_lr=.001后同时再放大梯度；所有周期仍连续，不添加把动作拉向中点的奖励。

探索由两部分组成：当前T附近的小幅局部连续噪声，以及覆盖整个范围的分层**连续**抽样，分层权重事先登记。局部数据支撑策略梯度的斜率，全范围数据支撑价值形状；仅后者不足以保证当前策略附近的斜率准确。锚点用于审计，不量化执行；不要给压缩后的动作直接叠噪声再截断。短区间和长区间都保留最低经验覆盖及窗口动作变化，不能仅“改变T、不让窗口适配”。最终冻结关闭探索；不靠随机熵或probe制造少调用的表面收益。

该参数化先做单变量离线能力试验。若不能在相同初始化下更稳定地辨别已知正/负周期优势，就不作为上线候选。

## 5. 价值学习：先建立分辨能力，再决定重参数化

保留一次成本.01、实际时间折扣以及双Q。新增已知解析正/零/负优势和状态相关最优连续T的任务，奖励及后继必须模拟“只改当前动作、后继由同一策略产生”，不能混用永久固定周期价值。既检查Q1/Q2的优势符号和相对误差，也检查部署actor选出的连续T及条件窗口是否匹配最优对。

建议解析任务门：有明确优势间隔的样本上排序准确率≥95%，优势MAE≤预先声明最小间隔的1/4；最优T与窗口必须随状态共同改变，不能以全选最长周期通过。成本0、常值效用的负控应无系统性周期价值偏好，而不是要求平局时每次输出必须固定不变。该门是新候选诊断标准，不是改写旧结果；真实TCP的优势真值/间隔不能凭当前critic自行生成。真实回放上的已知小额奖励注入只能验证受控拟合的分辨能力，不能把它说成真实TCP反事实Q认证。

一个可选而非必改的精确重参数化：冻结有界状态势Phi，写`Q=Phi+A`，训练残差target

`R + D*(1-d)*Phi(s1)-Phi(s0) + D*(1-d)*min(A1',A2')`。

同状态的周期排序不变，终止/人工截断须与原实现一致。Phi不准确时A仍可能很大，状态跳变会增加残差方差；因此它只改善拟合条件的可能性，不自动校准价值。先做代数等价、保存恢复、梯度及对真实数据残差尺度/方差检查，只有优于原拟合才采用。不能把未知区间平均效用、实际dt或TCP响应当已知可微解析项。

全局TD和短bootstrap回报仍用于执行与数值检查，但不再作为周期排序正确的充分门。新增按周期/状态分层的绝对误差、双Q优势分歧、独立短干预；在JOINT期间持续监测，不只在开放actor前检查一次。条件窗口新增的`dQ/da_c * da_c/dT`也可能被时间策略利用为critic高估通路，必须放进解析正负对照及真实分层检查，不能只核对链式梯度存在。

## 6. 奖励和TCP机制先诊断，分别改动

下一次少量云端核查优先读稳态cwnd/ssthresh、实际窗口倍率、ACK时钟和CUBIC运行阶段，区分slow start和CA。当前只掌握启动记录和库内patch，不能假定它们证明了在线内核全部行为。

若持续slow start、饱满ACK近似每RTT翻倍，抵消增长要求倍率约`2^(-T/RTT)`；结合最低1/4可得到条件近似T≤2RTT。**这不是当前系统已证明的硬上界**；ACK时钟、CUBIC非线性、在途包和整数截断都会改变推导。若控制范围限制真实存在，先报告方法限制；扩窗口范围、改ssthresh、停CUBIC均属独立算法/执行器变更，不偷偷改健康基座。

原Orca效用的延迟平台和端点SRTT需分别查：相同窗口族的少量连续周期干预，同时报告原效用、包级mean/P95、观测峰值变化、端点SRTT与区间平均RTT。现有960混合样本不能替代此因果诊断。必要时才单变量比较连续排队惩罚；那是普通性能目标，不是Canopy性质约束。不能把代码里读到了avg RTT等同于已经有无偏连续奖励积分，更不能加隐蔽20ms RL读取来改善奖励。

第一候选先不同时改奖励或盲目放大成本，避免无法判断结构/价值修复是否有效。若能可靠判断周期代价但原目标真实偏好20ms，再讨论显式性能—调用成本的可行折中系数及真实CPU结果。

可学习性门和最终晋升门分开，具体短训样本上限、冻结点、趋势阈值在未来网络预算前登记；本文件不自动授权新的小时数或训练次数。旧成本0的3.47M长训与本轮成本.01、冻结BN/teacher/探索/参数化均不同，不能用它断言新配方长训无用，也不能靠加时解决未核实的机制缺口。

当前仍遵守用户“不训练独立固定MTP组”。同权重强制周期/动作干预仅作诊断，不能据此声称优于独立训练的最佳固定周期。最终论文还需要相应强对照、动态网络和多个训练seed；不把当前阶段工程通过写成论文优势。
