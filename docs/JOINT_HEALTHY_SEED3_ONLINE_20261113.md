## 已经确认的事实

五台原环境独立部署，使用原内核、CUBIC 自然接管及健康 seed3 权重。原 baseline 入口、代码和模型不变。真实 TF1 核对 512 个输入的窗口输出误差为零；扩展 critic 的零填充权重经独立 float64 重建误差 8.53e-14。float32 GEMM 的微小差异单独记录，未改变性能门槛。

最初 24 次冻结测试均运行完成。G0 旧时钟/旧速率通过；G1 新调度/旧速率在两个条件的利用率损失为 1.2527 个百分点，超过事前 1pp 门槛；G2 新调度/ACK 自身峰值归一化在 G12-R200 排队 54.68ms，对照 13.11ms，未通过。负面结果保留，未开放该配方训练。

同一真实轨迹合并观测窗口时，ACK 自身峰值分母可造成约 2%—11% 的奖励变化。这是计量反事实，不是长周期控制收益，也不能精确重建其他周期下的内核估计器。

据此新增 G3：ACK 字节数除以实际间隔作为分子，采用同边界内核 delivery-rate 样本均值的历史峰值，供状态和 Orca 效用共用。没有容量 oracle、额外裁剪或性质奖励。效用形状保留，采样计量发生变化，不能称逐样本奖励与原基座完全相同。该分母也未被证明严格与 MTP 无关。

G3 四条件筛查及参照共 42 次完成，G3 利用率 99.5990%、平均排队 11.7667ms、条件等权 P95 19ms；同轮 baseline 为 99.5104%、10.3220ms、17.6083ms。总体筛查通过，但 G24-R20 的排队从 5.526ms 增至 8.623ms，不能说每个条件均改善。后续 G1 重复筛查通过，不能据此撤销首次失败或认定唯一原因。

## 工程修复与归因边界

- 共享 learner 通信改用原集群已验证的私网端点；SSH 使用严格已知指纹，没有放宽信任或改防火墙。最初通信失败时入库与优化均为零。
- native 先监听再启动客户端。此修复后仍有并发失败，因此不能称它是唯一原因。
- 实际 Mahimahi 源码的空闲地址扫描没有地址预留锁。现仅串行化命名空间构建至第一条真实动作，之后仍是 24 路并发。新增按本次流目录、客户端端口和创建时刻限定的孤儿进程清理。
- actor 只构建推理图；失败的 actor-host 返回失败状态，learner 无新数据时有界退出，避免无意义等待。
- 一条完整 60 秒测试因 TF tanh 比 -1 多出一个 float32 末位而被旧后处理误判：发送端正确裁剪并发送 25%，审计计算成 24%。审计现复用实际 wire 序列化。原 run 的 2699 个真实输入重建动作误差为零，保留原错误记录，仅恢复后处理，不重跑 TCP 挑成绩。

最终容量检查：1 learner＋24 actor，各至少 60 秒，共 50057 条真实入库、1440.615483 秒累计物理暴露、4925 完整 critic 迭代、9850 critic 优化器操作、4925 target 更新、actor 更新零。生成/入队/入库逐 actor 一致，协议、折扣、归一化及清理通过；在线和 target 窗口各 12 变量含 BN 逐位不变。终点为 `PARTIAL_CALIBRATION_ONLY`，不是完成联合学习。

## 通过后的唯一训练配方

独立 joint82、seed3、24 actor，各 1800 秒真实暴露，从原健康窗口初始化，fresh 优化器与回放，非容量 checkpoint 恢复。关闭性质、QC、fallback、容量 oracle 和调用成本。必须显式配置 `rate_mode=acked_legacy_peak`、`utility_normalization=legacy_delivery_peak`、`memsize=300000`；工厂默认 joint 配置保留历史 ACK-only 模式，不可直接误用。

回放从 150k 增至 300k 是显式配方变化：扣除独立留出块后，150k 在校准的非 20ms 桶内预计只能每 actor 保留约 114 条，不足 128 的覆盖门；300k 约 228 条。更新仍为每 20ms 等效真实入库暴露 0.1 次完整迭代，不按墙钟空增额度。

先冻结整个窗口及 BN 校准 critic，要求周期覆盖、独立 TD 与短段自举回报检查，再经过 40ms 前向校准后开放两动作。短段回报包含 bootstrap，不能称完整 MC 检查。终点按预定暴露选取，不从多个 checkpoint 挑最高成绩。需预留完整冻结评测、调用与真实 CPU 核对；只减少调用不能证明节省同等 CPU。

本轮没有独立训练固定周期强对照，不能据此证明自适应周期优于独立常数周期；也没有多 seed、动态或留出条件结论。大 checkpoint、replay 和逐包日志默认留云端，小证据增量回传。
