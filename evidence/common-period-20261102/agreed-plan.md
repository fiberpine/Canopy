## 0 已达成的技术选择

1. **真共周期。** MTP 同时决定观测和执行。沿用 V30 定时边界（`scheduled_observation_v30`）与 V31 新鲜度特征（`feedback_context_v31`）。不迟醒，不提前唤醒，无隐藏的 20 ms 采样，无 teacher、QC 或 fallback。
2. **原乘窗动作不变。** 每次决策乘一次 4^a，执行映射 `int(100·4^a)`。
3. **窗口以周期为条件：a = μ(s, T)。** 这是本轮的设计选择。不断言普通联合头必然失败，也不声称原双连续头已被验证。
4. **周期离散。** 候选为 {20, 40, 80, 120, 160} ms。窗口由 actor 学到，周期由学到的价值做 argmax（B0），两个动作都来自 RL。
5. **奖励 v1 与全局恒定速率中心化**（1.1、1.2 节）。
6. **训练稳定化：** 预激活 L2；近中性乘窗探索段；critic 先校准；actor 延迟更新；显式更新顺序；target 按完整变量名配对；带版本号的策略快照。
7. **不再从零重训单动作基座做比较。** 首次 A 是单 seed 的可行性筛查。

## 1 数学契约

### 1.1 SMDP 与中心化（势能形式）

- Γ = γ0^(dt/20 ms)，γ0 = 0.995，dt 为实际经过时间。区间奖励 R 沿用现有 `Interval` 积分，质量为 (1 − Γ)/(1 − γ0)。
- 势能：非终止状态 Φ = K，终止状态 Φ = 0，K = c/(1 − γ0)。c 为按物理暴露加权的每 20 ms 平均效用（规程见 4.1），估计后冻结。
- 中心化奖励 R' = R + Γ·Φ(s') − Φ(s)：
  - 非终止：R' = R − K(1 − Γ)。区间效用恒为 c 时 R = K(1 − Γ)，所以 R' = 0。
  - 真实终止：R' = R − K。
- 于是 Q' = Q − K。所有策略平移同一常数，周期之间的 argmax 不变。
- 禁止"每条 transition 直接减 c"：这等于加了每决策成本，会改变最优策略并偏向长周期。
- 回放保存未中心化的 R；采样时用冻结的 K 统一计算 R'。
- 决策成本不进入 R'，只在 B0 通过 N 使用。
- 在简化的常偏差模型中，统一偏移每次软更新只衰减 τ(1 − Γ)（τ = 0.001）。这只说明为什么要显式校准偏移，不作为历史 Q 上升主因的结论。

### 1.2 奖励 v1（A0 定稿后冻结，所有新训练一致）

- **效用：** u = 吞吐项 × 延迟因子 − 5 × 丢包项。延迟因子只乘吞吐项，净效用为负时，延迟增加不再减轻惩罚。
- **延迟因子：** min(1, 1.25 × minRTT / 区间平均 RTT)。区间平均 RTT 取内核读后清零累计量 `avg_urtt`。它是 ACK 采样均值，不是时间积分，也不是尾延迟；文中按代理目标表述。
- **零样本规则：** 区间 RTT 样本数为 0 时，延迟因子回退到边界 sRTT，并保留新鲜度标记。RTT 样本数为 0 不等于交付字节为 0（重传、Karn 规则等），回退的影响由 A0 量化，不预设很小。
- **归一化分母：** 只允许三类候选：
  1. 观测峰值（现行 `observed_peak`，因果）；
  2. 因果在线平滑峰值；
  3. 训练期冻结的单一全局速率尺度。

  禁止部署时按 trace 身份或真实容量查表。A0 的 shadow 审计在已有日志上检查三项：同一真实利用率下与周期无关；随真实交付单调；不出现低/高利用率别名。真实容量只用于离线审计。有限样本审计不能证明全局无别名或完全周期不变。
- **版本：** 149 维状态不变。只改奖励也要升版本号（版本与校验和写入 checkpoint 与回放），并重新校准 critic。

### 1.3 网络结构

- **周期编码：** t = 2·ln(T/20)/ln 8 − 1，与现有 `mtp_action` 相同。5 个候选对应 t ≈ −1、−0.333、0.333、0.723、1。
- **actor：** a = μ(s, t)。t 以独立加性项 w_t·t 接入第二隐藏层线性层（`fc2`，BN 之前），原矩阵乘法不变；w_t 置零，因此初始窗口输出与 V31 逐位相同。online 与 target actor 结构一致；输出仍经 tanh。V31 的时间头不再使用。
- **critic：** 双 critic Q(s, a, t)，沿用 V31 结构（动作在第二层输入），时间动作输入改为候选的 t。
- **N 网络：** 独立小网络 N(s, a, t) = n0(T) + r(s, a, t)，r 零初始化，不与 Q 共享参数。
- **初始化：** online 与 target 均从 V31 step157704 载入窗口头、critic 与 BN 统计；critic 及其 target 的输出偏置先减 K，再按 4.1 校准。

### 1.4 阶段 A 的学习目标

- **Q：** y = R' + Γ·min(Q1', Q2')(s', ã', t)，其中 ã' = clip(μ'(s', t) + ε, −1, 1)，ε 为目标平滑噪声（沿用现有实现：N(0, 0.1)，裁剪到 ±0.2，只加在窗口动作上）。t 取该条经验执行的周期（同周期继续）。只用一步目标，不用跨段 n 步回报。结束类型的处理见第 2 节。
- **actor：** 损失为 −Q1(s, μ(s, t), t) + λ_z·mean(z²)。t 取该条经验执行的周期；z 为窗口输出的预激活，取自与 actor 损失相同的前向（现有 `backend: moving_stats`）。RL 梯度与正则梯度分开记录；只有 RL 梯度恢复才算复活证据。
- **N：** 目标为 1 + Γ·N'(s', μ'(s', t), t)（真实终止时为 1）；部署时查询 N(s, μ(s, t), t)。
  - 先验 n0(T) = 1/(1 − mean_T(Γ))，用 A 阶段数据估计后冻结。它只是初值，不是状态条件的真值。
  - 不用 1/(1 − γ0^(mean dt/20 ms))，两者有 Jensen 差异。
  - r 的梯度不进入 Q 的参数。

### 1.5 B0 前的确定性策略评估

A 的目标平滑与双 Q 取 min，得到的不是最终确定性窗口族的精确价值。因此在 B0 之前：

- 冻结 μ 与 BN，关闭目标平滑与探索。
- 做固定更新预算的 critic-only 评估：每个 critic 回归自己的目标 y_i = R' + Γ·Q_i'(s', μ(s', t), t)，不取 min；N 同样按确定性 μ 评估。数据为 A 结束时的训练回放（校准数据从不进入），不新采训练数据。
- 评估结束后冻结全部网络，再做 4.2 的复检与 λ 扫描。"选择器本身不再训练"成立，但 B0 包含这一 critic-only 阶段，不称零优化。

### 1.6 B0 的选择规则与表述边界

- 每个决策点对 5 个候选批量计算：a_i = μ(s, t_i)；Q̄_i 为 (Q1 + Q2)/2 在 (s, a_i, t_i) 处的值；N_i = N(s, a_i, t_i)。选 argmax_i (Q̄_i − λ·N_i)，评测时无探索。
- 选择用两个 critic 的均值：1.5 的评估不取 min，两个 critic 估计的是同一确定性策略的价值；再取 min 会引入随两者分歧而变的悲观偏差，偏向数据多的周期。
- **表述边界：** 这是已学窗口族内的策略切换（GPI）。在理想 Markov SMDP 且各值精确时，按此规则切换的策略不劣于族内任一固定周期策略（以含 λ·N 成本的目标计）。部分观测与近似 Q 下不构成保证，网络质量只由实验判定。λ 扫描只调整成本取舍，不是各 λ 下的联合最优。

## 2 数据契约

- **回放字段：** s；实际执行的 (a, t)；未中心化 R 与奖励版本；s'；dt；Γ；结束类型；连接 ID；策略快照版本；行为来源（随机分段 / 近中性段 / 策略）。
- **结束类型：**

  | 类型 | 含义 | 目标 |
  |---|---|---|
  | terminated | 任务定义上的真实结束 | Φ_terminal = 0，R' = R − K，不 bootstrap |
  | truncated | 时间截断（如定时重连、预算结束） | 只有同一连接的真实下一状态可用时才 bootstrap，否则改记 censored |
  | censored | 没有合法下一状态（如网络失败、异常重连） | 排除，不伪造 |

  - 禁止 bootstrap 到另一个 TCP 连接的 reset 状态。
  - 现有配置每 180 s 重连一次（`connection_reset_seconds`，各 actor 错开 0.5 s）。各类事件归入哪种类型，在 A0 登记。
- **探索（A）：**
  - 周期从 5 个候选中均匀抽取，每段保持 1–5 s。
  - 窗口为 μ(s, t) + N(0, 0.2)，裁剪到 [−1, 1]。
  - 近中性乘窗探索段：按物理时间每秒以 5% 的概率进入，每段 0.5–1 s，执行原定义下的 a = 0（100%，仍调用 setsockopt），回放如实记录。训练回放中不得出现 `APPLY=0` 行。
- **校准数据隔离：** 4.1 与 4.2 的所有校准块和校准连接都不进入训练回放。

## 3 实现契约

- **更新顺序：** critic → actor（每 2 次 critic 更新 1 次）→ BN 统计 → target，用控制依赖固定。Q1、Q2、actor、N 各自使用独立优化器与优化器状态；A 开始时重置 Adam 状态。N 的更新与 target 同步顺序在 A0 明确登记。
- **更新额度：** A 仅按实际入库的真实训练经验发放更新信用；不入回放的校准数据不产生信用。A 开始的 5,000 次 critic 先校准从该信用账本支出，不能在尚无训练经验时凭校准块或墙钟发放。B0 的 critic-only 评估则使用另行登记、封顶的离线更新预算，不来自新经验信用。两类更新分别计数，不混称。
- **target 配对：** 按完整变量名一一配对，断言每个 target 变量每次只赋值一次；保持 `target_bn_consistent`。
- **梯度与动作报告：** 每 100 次更新按周期记录 RL 梯度范数（∂Q/∂a 经 tanh）、正则梯度范数，以及无噪声窗口 |a| > 0.99 的比例。
- **策略快照：** 带版本号；actor 侧为每条经验记录所用版本。
- **CPU 测量（部署模式）：** 关闭 Python 逐步日志；5 个候选的推理批量完成；分别报告推理时间、Python、native 与总归属 CPU，统一采用含 Mahimahi 的口径。

## 4 固定预算内的校准

### 4.1 A 开始时（计入 A 的 1800 s/actor）

1. 每个 actor 先跑 5 个校准块，每个候选周期一个：冻结初始窗口策略、无探索、固定周期，每块 ≥ 40 s，块不跨连接（每 180 s 重连，5 块至少分布在 2 个连接里）。共约 200 s/actor。
2. 用全部校准块按物理暴露估计 c，冻结 K；同时按周期估计 mean_T(Γ)，得到 n0(T)。
3. 对每块前 20 s 内且具备合法后缀的决策点，计算实际持续时间 H ≥ 20 s 的同周期回报标签：`G_H = Σ_j (Π_{l<j} Γ_l) R'_j + Γ_H V_frozen(s_H,T)`，其中 `Γ_H = Π_j Γ_j`，尾项来自冻结的同一确定性窗口策略及 critic 均值。后缀及尾状态不得跨连接。20 s 的折扣约为 0.00665，但这不等于尾项误差可忽略；必须报告尾项及其不确定性，不能将该标签称为已知的真实无限时域回报。
4. 24 个 actor 预先分为拟合组和复检组，各 12 个，名单在 A0 登记。若冻结尾项及当前 critic 都带同一个加性偏差 e，则 `E[G_H − Q̄'] = −e(1−Γ_H)`。因此一次性统一校正采用 `b = mean(G_H − Q̄') / mean(1−Γ_H)`，加到两个 critic 及其 target 的输出偏置；若采用加权均值，分子分母必须使用同一组预登记权重。该修正在统一偏差模型下成立，不保证一般的状态/周期相关误差已消除。复检组独立检查，不得循环补偏置直到过关。复检结果如实记录，不作为 A 的停止条件（A 的去留只看 6.1）。
5. Q_old − K 只是先验，不是新奖励下校准好的 Q；之后由 5,000 次只更新 critic 的先校准继续拟合。

### 4.2 B0（计入 B0，属于优化）

1. 按 1.5 做固定预算的 critic-only 策略评估。
2. **训练校准集：** 冻结全部网络，运行两类块：
   - 固定周期块：各候选周期，无探索，≥ 40 s；
   - 切换块：先以 T1 运行一段，再在随机时刻切到 T2，并保持 ≥ 20 s。

   估计各周期的统一偏差、偏差随周期的趋势和切换后偏差。必要时在此集合上做**一次**按周期偏置修正（固定策略、奖励与时钟）。
3. **独立留出校准集：** 同样两类块，另加分层随机切换：按条件 × 阶段分层，在决策点随机指定下一周期并保持 ≥ 20 s。留出集只用于复检，检查各周期偏差、切换后偏差、各层平均偏好（critic 预测与实测回报之差）及其不确定性。任一项不过预登记阈值，即停止 B0，不再调整，不得用测试集调整。
4. 分层随机切换只估计分层（区组）平均偏好，不是逐状态的 argmax 遗憾；平均分箱偏差小，也不作为统一误差的证书。
5. 校准连接只用开发 trace，不与测试集重叠；条件、数量与时长在 A0 登记。

## 5 A0：离线检查与运行前登记

A0 先做本机代码实现、已有数据审计和离线检查，0 TCP。需要原 TF 环境才能完成的检查单列为云端离线项目，纳入明确预算；不能因本机不能构图而跳过模型契约。全部必需检查通过、登记文件冻结后，才进入已授权的 A。可选复活测试失败或未执行不冒充必需项通过，也不自动阻断其余准备。

| 检查 | 通过条件 |

## 6 去留标准

### 6.1 A：可行性筛查（单 seed；对照都是外部参照）

- **评测：** A 网络强制在 5 个周期下运行；同日参照为 fixed80/120/160、H0、官方 Orca、CUBIC；12 个开发条件 × 2 次，随机顺序。
- **通过（数值以 A0 登记为准，以下为提案）：**
  1. 动作健康：每个周期、每个条件的无噪声窗口 |a| > 0.99 的比例 < 5%。
  2. 长周期（80/120/160）：12 条件均值利用率不低于同日同周期参照 1 pp 以上；任一条件不低于参照 5 pp 以上；平均排队与 P95 不超过参照的 1.25 倍。
  3. 短周期（20/40）：每个 R100 条件利用率 ≥ 90%；12 条件均值利用率不低于同日 H0 与官方 Orca 中较低者 2 pp 以上；P95 不超过该参照的 1.5 倍。
  4. 逐条件报告 P95/P99、启动窗口（前 10 s 与全程，不能只看 trim10）以及重复间差异。
- 这些参照都是旧奖励训练的外部参照，只用于判断可行性，不支撑算法因果结论。
- **失败：** 只否定这一候选。复盘空观测比例、窗口饱和与价值偏移后，由用户决定是否追加 seed、启用"每个周期一个窗口输出层"的变体，或单独验证迟醒；不自动删除 20 ms。

### 6.2 B0：价值驱动的周期选择

- **前提：** 4.2 的校准全部通过。
- **匹配对照：**
  - 同一 A 网络强制各固定周期得到的点，及完整独立连接层面的随机混合凸包：每条连接开始前随机选一个固定周期，整条连接保持，混合权重对所有条件统一。各 run 指标的期望可做凸组合；这不代表同一 TCP 连接内的时间分享，因为连接状态具有记忆。P95/P99 若定义为各 run 分位数的期望，可按该口径组合；若定义为合并流量分位数，必须由原始分布重算，不能线性混合分位数；
  - 规则调度（现有 `hysteresis` 模式）配同一 A 网络。
- **外部参照：** 同日的 V31。
- **通过需同时满足：**
  1. 网络指标在预登记的非劣界内（逐条件利用率、平均排队、P95/P99、启动窗口）。
  2. 相对凸包前沿与规则调度都有严格、可重复的收益：与网络指标不劣于 B0 的最低 CPU 混合相比，B0 的实际 CPU 更低（配对差异的置信区间下界 > 0）；或与 CPU 不高于 B0 的混合相比，B0 的网络指标严格更好。调用次数减少只作辅助证据。
  3. λ 在第 1 次重复上按预登记规则选定；条件 1、2 只用独立的第 2 次重复及预登记的额外确认重复检验。两重复分离只作开发筛查，单条件仅一次确认不能证明稳定性；独立重复不足以支持置信区间时标记 PARTIAL。所需追加确认重复在运行前列入清单另批，不因结果接近门槛而临时追加。
- "非支配"不够：永远选同一个固定周期也可能非支配，不能算自适应创新。
- **结果不确定：** 标记为 PARTIAL。校准通过但无收益时，可在已审核、相位变化更多的 trace 上再试一次；仍无收益，就如实降低论文主张。

### 6.3 C：多 seed 留出验证

- A 再做 2 个 seed（共 3 个），每个 seed 各自完成 4.1、4.2 与 B0。
- 测试集只用 A0 审核通过的 trace，并注明历史曝光。
- 报告逐条件利用率、平均/P95/P99 排队、丢包、启动窗口、调用/秒与部署模式 CPU，附跨 seed 区间；所有失败一并报告。

- 计划中每次正式冻结评测 60 s。A 的 264 次对应 15,840 run-seconds；B0 的 168 次对应 10,080 run-seconds，另有校准、离线优化及必要的 120 次同轮固定周期评测（7,200 run-seconds）。这些不是墙钟耗时，需按验证过的并发和启动开销折算。
- 独立确认重复数不足时，先在清单中补足预算；预算不够则预先缩小可支持的结论，不能事后把筛查当作稳定性证明。
- 为冻结评测、保存、停止及进程/IPC 核查预留明确时间。余量不足以完成下一个原子实验时不启动；不得用评测预留偷偷延长训练。
- 训练样本数、完整双 critic 迭代数、两个 critic 的优化器操作数、actor/N/target 更新数分别报告。名义 1800 s 不自动代表足够学习，完成一次也不代表收敛。
- 截止时间到达或用户要求停止时，先阻止调度器启动新任务，再停止归属进程、排空合法经验、保存并核查；不得自动续用历史剩余预算。
